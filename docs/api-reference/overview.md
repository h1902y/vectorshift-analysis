## API Keys

You view your API keys and generate new ones by navigating to the API Keys page in your settings. To access this page:

1. Click on the VectorShift logo in the top-left corner of the page, and click "Profile".
2. Click the "API Keys" tab on the left.

Here, you can view your existing API keys, and you can generate new ones by clicking the "+" button in the top-right corner of the section.
