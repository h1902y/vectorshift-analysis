# Ready-to-use templates

> Browse pre-built templates you can import and start using today - each one solves a specific business problem out of the box

Every template below is ready to import into your workspace. Pick one, click through to the Marketplace, and you will have a working starting point you can customize with your own data, prompts, and integrations.

To import any template, go to **Marketplaces** in the left sidebar, search for the template by name, and click **Save Workflow**. For a full walkthrough, see [Marketplace overview](/platform/marketplaces/overview).
