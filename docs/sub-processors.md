# Sub-processors

> Third parties that process Customer Data on VectorShift behalf

VectorShift engages the following sub-processors to help provide its services. Each processes Customer Data only as needed to deliver the service and under appropriate data-protection terms.

## Infrastructure

| Sub-processor                 | Purpose                      | Location      |
| ----------------------------- | ---------------------------- | ------------- |
| Amazon Web Services (AWS)     | Cloud hosting & file storage | United States |
| MongoDB Atlas (MongoDB, Inc.) | Managed database hosting     | United States |

## AI / LLM model providers

Used for inference when a customer selects the model.

| Sub-processor               | Purpose       | Location      |
| --------------------------- | ------------- | ------------- |
| OpenAI                      | LLM inference | United States |
| Anthropic                   | LLM inference | United States |
| Google (Gemini / Vertex AI) | LLM inference | United States |

Additional providers a customer may select: Microsoft Azure OpenAI, AWS Bedrock, Cohere, Mistral, Meta Llama hosts, xAI, Perplexity, Groq, Together AI, Fireworks.

<Note>
  Customers who supply their own model-provider API keys ("bring your own key") engage those providers directly under the customer's own agreement; in that case the provider is not acting as a VectorShift sub-processor.
</Note>
